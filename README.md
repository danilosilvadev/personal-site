# personal-site

A one-page personal site. React + Vite + TypeScript, no other dependencies.

```
npm install
npm run dev      # http://localhost:5173
npm run build    # type-checks, then writes dist/
```

All the words, links and lists are in `src/content.ts`; the look is `src/styles.css` (colours are the variables at the top, with a dark mode). Links set to `#` are placeholders. The email box is not connected to a service until you set `subscribe.action`.
